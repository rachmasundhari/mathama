# Mengalikan dan Membagi Bentuk Aljabar

Materi ini memuat konsep lengkap untuk subbab ini. Cerita Bab 4 ada di akhir bab.

**Tujuan belajar:** Mengalikan dan membagi bentuk aljabar sederhana, termasuk membuka kurung dengan sifat distributif.

**Kata kunci:** perkalian, pembagian, kurung, sifat distributif, faktor, suku.

## 1. Konsep

Tiga kantong hadiah berisi satu kotak pensil dan dua penghapus. Isi kotak pensil belum diketahui, jadi diberi nama $x$. Satu kantong berisi $x + 2$ benda. Tiga kantong berisi:

$$3(x + 2)$$

Bentuk itu dibaca sebagai tiga kelompok, setiap kelompok berisi $x$ dan 2. Hasilnya tiga kotak pensil dan enam penghapus:

$$3(x + 2) = 3x + 6$$

Menulis $3x + 2$ berarti tiga kotak dan dua penghapus. Itu hanya satu kantong ditambah dua kantong kosong, bukan tiga kantong penuh. Setiap kantong menyumbang dua penghapus, jadi penghapusnya berjumlah $3 \times 2 = 6$.

Perkalian bentuk aljabar dengan satu bilangan memakai **sifat distributif**:

$$a(b + c) = ab + ac$$

Aturan yang sama berlaku untuk pengurangan:

$$4(2x - 3) = 4 \times 2x - 4 \times 3 = 8x - 12$$

Jika $x = 5$, sisi kiri $4(10 - 3) = 4 \times 7 = 28$. Sisi kanan $8(5) - 12 = 40 - 12 = 28$. Keduanya sama.

Setiap suku di dalam kurung mendapat faktor yang sama. Kalau suku di dalamnya sudah punya koefisien, koefisien itu ikut dikalikan. $3(4x) = 12x$, dan $2(5a + 3b) = 10a + 6b$.

Pembagian bentuk aljabar memakai gagasan yang mirip. Setiap suku dibagi dengan pembaginya.

$$\frac{12x}{4} = 3x$$

$$\frac{15x + 10}{5} = \frac{15x}{5} + \frac{10}{5} = 3x + 2$$

Pembagian dapat diperiksa dengan perkalian:

$$5(3x + 2) = 15x + 10$$

Hasilnya kembali ke bentuk awal.

## 2. Contoh

Contoh 1. Dua belas kantong, setiap kantong berisi $x$ pensil dan 2 penghapus.

$$12(x + 2) = 12x + 24$$

Jika $x = 6$, jumlah pensil $12 \times 6 = 72$ dan penghapus $12 \times 2 = 24$. Seluruhnya 96 benda. Cara lain: satu kantong berisi $6 + 2 = 8$ benda, lalu $12 \times 8 = 96$.

Contoh 2. Setiap kantong berisi $x$ pensil dan 3 penghapus.

$$12(x + 3) = 12x + 36$$

Jika $x = 6$, pensilnya 72 dan penghapusnya 36. Seluruhnya 108 benda.

Contoh 3. Harga. Satu paket berisi satu buku dan dua pensil. Harga buku $x$ rupiah dan harga pensil Rp2.000. Harga delapan paket:

$$8(x + 4.000) = 8x + 32.000$$

Jika $x = 6.000$, harganya $8(6.000) + 32.000 = 80.000$ rupiah.

Contoh 4. Pembagian. Uang kas sebesar $12x$ rupiah dibagi rata untuk 4 kelompok.

$$\frac{12x}{4} = 3x$$

Jika $x = 5.000$, setiap kelompok mendapat $3(5.000) = 15.000$ rupiah. Periksa: $4 \times 15.000 = 60.000$, sama dengan $12(5.000)$.

Contoh 5. Pembagian dengan dua suku.

$$\frac{18x + 12}{6} = 3x + 2$$

Periksa dengan $x = 4$: $(72 + 12) \div 6 = 84 \div 6 = 14$, dan $3(4) + 2 = 14$.

Contoh 6. Pembagian yang tidak habis per suku tidak disederhanakan dengan cara ini. $\frac{5x + 3}{2}$ tetap ditulis sebagai satu pecahan karena 3 tidak habis dibagi 2.

Contoh 7. Kantong berisi $x$ pensil dan $y$ penghapus. Enam kantong berisi:

$$6(x + y) = 6x + 6y$$

Jika $x = 4$ dan $y = 3$, isinya $6(4) + 6(3) = 24 + 18 = 42$ benda.

Contoh 8. Pembagian dipakai untuk memeriksa isi dus. Delapan dus berisi 120 pensil, jadi satu dus berisi $120 \div 8 = 15$ pensil. Kalau label dus $2x + 3$, persamaan $2x + 3 = 15$ memberi $x = 6$. Periksa dengan perkalian: $2(6) + 3 = 15$.

## 3. Lab

Ubah jumlah kelompok dan nilai $x$. Lab menampilkan $a(x + 2) = ax + 2a$.

<DistributiveLab />

Dengan 3 kelompok dan $x = 4$, sisi kiri $3(4 + 2) = 18$ dan sisi kanan $3(4) + 6 = 18$. Dengan 4 kelompok, bentuknya $4(x + 2) = 4x + 8$. Jumlah kelompok menentukan koefisien $x$ dan banyak penghapus.

## 4. Kesalahan umum

- Menulis $3(x + 2)$ sebagai $3x + 2$. Angka 3 harus dikalikan ke $x$ dan ke 2.
- Menghitung penghapus hanya satu kantong. Tiga kantong berarti $3 \times 2 = 6$ penghapus.
- Lupa mengalikan tanda minus. $4(2x - 3) = 8x - 12$, bukan $8x - 3$.
- Membagi hanya suku pertama. $\frac{15x + 10}{5}$ harus menjadi $3x + 2$, bukan $3x + 10$.
- Membalik urutan operasi. Bagi setiap suku, bukan hasil penjumlahannya saja.
- Tidak memeriksa hasil. Substitusi satu nilai $x$ menunjukkan apakah kurung sudah dibuka dengan benar.

## 5. Ringkasan

- $a(b + c) = ab + ac$.
- $a(b - c) = ab - ac$.
- $3(x + 2) = 3x + 6$.
- $4(2x - 3) = 8x - 12$.
- $12(x + 2) = 12x + 24$.
- $\frac{12x}{4} = 3x$.
- $\frac{15x + 10}{5} = 3x + 2$.
- Pembagian dapat diperiksa dengan mengalikan hasilnya kembali.
- Periksa hasil aljabar dengan mengganti variabel memakai bilangan yang mudah.
