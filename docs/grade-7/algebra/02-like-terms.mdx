# Suku Sejenis dan Penyederhanaan

Materi ini memuat konsep lengkap untuk subbab ini. Cerita Bab 4 ada di akhir bab.

**Tujuan belajar:** Mengenali suku sejenis dan menyederhanakan bentuk aljabar dengan menggabungkan koefisiennya.

**Kata kunci:** suku, suku sejenis, suku tidak sejenis, koefisien, konstanta, menyederhanakan.

## 1. Konsep

Tiga dus berlabel $2x + 3$, $3x$, dan $x + 5$ akan dijumlahkan. Setiap dus berisi kotak bernama $x$ dan pensil lepas. Kotak hanya boleh digabung dengan kotak. Pensil lepas hanya boleh digabung dengan pensil lepas.

<img className="lessonIllustration" src={useBaseUrl('/img/lessons/g7-algebra-like-terms-01-objek.webp')} alt="Kotak pensil dan pensil lepas dipisahkan menjadi dua kelompok di atas meja" />

**Suku sejenis** adalah suku yang variabel dan pangkatnya sama. Koefisiennya boleh berbeda. $2x$ dan $3x$ sejenis karena keduanya memuat $x$ pangkat satu. $5a$ dan $2a$ juga sejenis. Sebaliknya, $6x$ dan 8 tidak sejenis karena 8 tidak memuat $x$. $3x$ dan $3x^2$ tidak sejenis karena pangkatnya berbeda.

Untuk menjumlahkan suku sejenis, jumlahkan koefisiennya dan biarkan variabelnya. Konstanta dijumlahkan dengan konstanta.

$$2x + 3x + x = (2 + 3 + 1)x = 6x$$

$$3 + 5 = 8$$

Hasil lengkapnya:

$$(2x + 3) + (3x) + (x + 5) = 6x + 8$$

Bentuk $6x + 8$ berarti enam kotak dan delapan pensil lepas. Kedua suku tidak bisa digabung lagi karena jenisnya berbeda. Menyederhanakan bentuk aljabar berarti menggabungkan suku sejenis. Hasilnya boleh tetap punya dua suku atau lebih kalau jenisnya berbeda.

Pengurangan memakai aturan yang sama, tetapi tanda minus berlaku untuk semua suku di dalam kurung. Kalau satu dus berlabel $x + 5$ diambil dari total, yang berkurang adalah satu kotak dan lima pensil.

$$6x + 8 - (x + 5) = 6x + 8 - x - 5 = 5x + 3$$

## 2. Contoh

Contoh 1. Sederhanakan $4a + 7 + 2a + 3$.

Kumpulkan suku sejenis:

$$(4a + 2a) + (7 + 3) = 6a + 10$$

Contoh 2. Sederhanakan $8m - 3n + 2m + 5n$.

$$(8m + 2m) + (-3n + 5n) = 10m + 2n$$

Contoh 3. Sederhanakan $5x + 2 - 3x + 6$.

$$(5x - 3x) + (2 + 6) = 2x + 8$$

Contoh 4. Periksa hasil $(2x + 3) + (3x) + (x + 5) = 6x + 8$ dengan $x = 6$.

Cara cepat:

$$6(6) + 8 = 36 + 8 = 44$$

Cara satu per satu:

$$2(6) + 3 = 15$$

$$3(6) = 18$$

$$6 + 5 = 11$$

$$15 + 18 + 11 = 44$$

Kedua cara memberi hasil yang sama. Pemeriksaan dengan satu nilai cukup untuk menangkap banyak kesalahan penjumlahan.

Contoh 5. Setelah satu dus berlabel $x + 5$ diambil, sisanya $5x + 3$. Untuk $x = 6$, nilainya $5(6) + 3 = 33$. Cara lain, total 44 dikurangi isi dus yang diambil, yaitu 11, juga memberi 33.

Contoh 6. Meja A berisi 3 kotak pensil dan 4 pensil lepas. Meja B berisi 2 kotak pensil dan 7 pensil lepas. Satu kotak berisi $x$ pensil. Isi kedua meja:

$$(3x + 4) + (2x + 7) = 5x + 11$$

Jika $x = 8$, isinya $5(8) + 11 = 51$ pensil. Cara satu per satu: meja A berisi $3(8) + 4 = 28$, meja B berisi $2(8) + 7 = 23$, dan jumlahnya 51.

Koefisien boleh bernilai negatif. $7x - 2x = 5x$, sedangkan $-4a + 9a = 5a$. Yang dijumlahkan tetap koefisiennya, termasuk tandanya.

## 4. Kesalahan umum

- Menjumlahkan $2x + 3 + 3x$ menjadi $8x$. Angka 3 adalah pensil lepas, bukan kotak, jadi tidak ikut menjadi $x$.
- Menulis total tiga dus sebagai $14x$. Isi kotak dan pensil lepas tidak boleh disatukan.
- Menggabungkan $6x$ dan 8 menjadi $14x$. Keduanya berbeda jenis.
- Menyamakan $5a$ dan $5a^2$ karena hurufnya sama. Pangkat yang berbeda membuat suku tidak sejenis.
- Mengurangi $6x + 8 - (x + 5)$ menjadi $5x + 13$. Tanda minus harus dikenakan pada $x$ dan pada 5.
- Menganggap $x$ dan $y$ sejenis karena sama-sama huruf. Variabel yang berbeda jenisnya berbeda.

## 5. Ringkasan

- Suku adalah bagian bentuk aljabar yang dipisahkan tanda plus atau minus.
- Suku sejenis memiliki variabel dan pangkat yang sama.
- Koefisien suku sejenis boleh berbeda dan dapat dijumlahkan.
- Konstanta hanya dapat digabung dengan konstanta.
- $2x + 3x + x = 6x$, sedangkan $3 + 5 = 8$.
- $(2x + 3) + (3x) + (x + 5) = 6x + 8$.
- Tanda minus di depan kurung berlaku untuk setiap suku di dalam kurung.
- Periksa hasil penyederhanaan dengan substitusi satu nilai variabel.
