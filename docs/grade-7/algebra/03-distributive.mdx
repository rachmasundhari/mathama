# Sifat Distributif

Materi ini memuat konsep lengkap untuk subbab ini. Cerita Bab 4 ada di akhir bab.

**Tujuan belajar:** Menggunakan sifat distributif untuk membuka kurung dan menghitung nilai bentuk aljabar dengan dua jenis suku.

**Kata kunci:** sifat distributif, kurung, faktor, suku, perkalian, pengurangan.

## 1. Konsep

Pekan Angka punya empat booth hadiah. Setiap booth memberi hadiah untuk 5 pemenang, yaitu 3 hadiah per pemenang, lalu menambah 4 hadiah cadangan. Banyak hadiah satu booth adalah $3 \times 5 + 4 = 19$. Empat booth membutuhkan $4 \times 19 = 76$ hadiah.

Hitung cepat $4 \times 3 \times 5 + 4$ memberi 64. Hasil itu kurang 12. Bagian yang tertinggal adalah empat kelompok cadangan, karena angka 4 di depan hanya dikalikan ke $3 \times 5$. Setiap booth punya cadangan, jadi keempat kelompok cadangan harus ikut dihitung.

Aturan yang benar disebut **sifat distributif**:

$$a(b + c) = ab + ac$$

Bilangan di luar kurung dikalikan ke setiap suku di dalam kurung. Untuk empat booth:

$$4(3 \times 5 + 4) = 4(15) + 4(4) = 60 + 16 = 76$$

Aturan yang sama berlaku untuk pengurangan:

$$a(b - c) = ab - ac$$

Tanda minus ikut dikalikan. Contoh sederhana:

$$2(x + 3) = 2x + 6$$

Kalau 2 hanya dikalikan ke $x$, hasilnya $2x + 3$. Angka 3 kehilangan faktor 2, jadi hasilnya tidak sama dengan bentuk asal.

Sifat distributif juga berlaku untuk kurung dengan tiga suku:

$$2(x + y + 3) = 2x + 2y + 6$$

Setiap suku di dalam kurung mendapat faktor yang sama.

## 2. Contoh

Contoh 1. Hadiah untuk empat booth. Misalkan setiap pemenang mendapat 3 hadiah dan banyak pemenang adalah $b$. Satu booth berisi $3b + 4$ hadiah, karena ada 4 cadangan.

$$4(3b + 4) = 12b + 16$$

Untuk $b = 5$:

$$12(5) + 16 = 60 + 16 = 76$$

Cara kedua: satu booth berisi $3(5) + 4 = 19$ hadiah, lalu $4 \times 19 = 76$.

Contoh 2. Dua booth demo mendapat $2b + 1$ hadiah per booth.

$$2(2b + 1) = 4b + 2$$

Seluruh hadiah menjadi:

$$12b + 16 + 4b + 2 = 16b + 18$$

Untuk $b = 5$, hasilnya $16(5) + 18 = 98$ hadiah.

Contoh 3. $3(5x + 2) = 15x + 6$. Jika $x = 4$, nilainya $15(4) + 6 = 66$. Cara lambat: $5(4) + 2 = 22$, lalu $3 \times 22 = 66$.

Contoh 4. $5(2x - 3) = 10x - 15$. Jika $x = 4$, sisi kiri $5(8 - 3) = 25$. Bentuk $10(4) - 15 = 25$ juga benar. Kalau tanda minus tidak dikalikan dan ditulis $10x - 3$, hasilnya $40 - 3 = 37$, jadi tidak sama.

Contoh 5. Harga. Satu paket alat tulis berisi satu pensil dan dua penghapus. Harga pensil $x$ rupiah dan harga penghapus Rp1.500. Harga satu paket $x + 3.000$ rupiah. Harga lima paket:

$$5(x + 3.000) = 5x + 15.000$$

Jika $x = 2.000$, harga lima paket $5(2.000) + 15.000 = 25.000$ rupiah.

Contoh 6. Harga enam kotak hadiah. Setiap kotak berisi dua pensil, dan ada potongan Rp500 untuk setiap kotak. Harga satu kotak adalah $2x - 500$ rupiah, dengan $x$ harga satu pensil.

$$6(2x - 500) = 12x - 3.000$$

Jika $x = 1.500$, harga enam kotak $12(1.500) - 3.000 = 18.000 - 3.000 = 15.000$ rupiah. Cara lain: satu kotak $2(1.500) - 500 = 2.500$, lalu $6 \times 2.500 = 15.000$.

Pemeriksaan sebaiknya memakai nilai yang tidak nol. Kalau $x = 0$, banyak kesalahan tanda tidak terlihat karena hasilnya bisa kebetulan sama.

## 3. Lab

Ubah jumlah kelompok dan nilai $x$. Kedua sisi harus tetap sama.

<DistributiveLab />

Dengan 4 kelompok dan $x = 2$, sisi kiri $4(2 + 2) = 16$. Sisi kanan $4 \times 2 + 4 \times 2 = 8 + 8 = 16$. Dengan 3 kelompok dan $x = 5$, kiri $3(5 + 2) = 21$ dan kanan $3 \times 5 + 3 \times 2 = 15 + 6 = 21$.

Geser nilai $x$ dan jumlah kelompok. Selama aturan distributif dipakai, kedua sisi bertemu di angka yang sama.

## 4. Kesalahan umum

- Mengalikan faktor luar hanya ke suku pertama. $4(3b + 4)$ bukan $12b + 4$.
- Lupa mengalikan tanda minus. $5(2x - 3) = 10x - 15$, bukan $10x - 3$.
- Menambahkan faktor luar ke isi kurung. $2(x + 3)$ bukan $2x + 3$ dan bukan $x + 5$.
- Membuka kurung dengan tiga suku tetapi melewatkan satu suku. $2(x + y + 3)$ harus menjadi $2x + 2y + 6$.
- Menganggap $a(b + c)$ sama dengan $ab + c$. Hanya perkalian yang boleh disebar, bukan penjumlahan di luar.
- Tidak memeriksa hasil. Substitusi satu nilai $x$ yang mudah cepat menunjukkan kurung yang belum terbuka benar.

## 5. Ringkasan

- Sifat distributif: $a(b + c) = ab + ac$.
- Untuk pengurangan: $a(b - c) = ab - ac$.
- Faktor di luar kurung dikalikan ke setiap suku di dalam kurung.
- $4(3b + 4) = 12b + 16$.
- $2(2b + 1) = 4b + 2$.
- $3(5x + 2) = 15x + 6$.
- $5(2x - 3) = 10x - 15$.
- Periksa hasil dengan mengganti variabel memakai bilangan yang mudah dihitung.
